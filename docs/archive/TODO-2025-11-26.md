## Strategic Decisions Pending

### Decision 0: FLUX.2 vs Qwen-Edit Strategy (NEW - URGENT)
**Question**: Should we pivot to FLUX.2-dev multi-reference approach?

**FLUX.2 Advantages**:
- Native multi-reference support (up to 10 photos)
- Could generate variations directly from source images
- Already running locally (4-bit GGUF in ComfyUI)
- Official black-forest-labs release
- Potentially simpler pipeline (no separate editor model)

**Qwen-Edit Advantages**:
- More precise control over specific edits
- Proven ecosystem of specialized LoRAs
- Already invested time in setup/testing
- Image-to-image editing more flexible

**Options**:
- A) 🆕 Pivot to FLUX.2 multi-reference → Test character consistency
- B) 🔀 Hybrid: FLUX.2 for generation + Qwen for refinement
- C) ✅ Continue with Qwen-Edit → FLUX.2 as future optimization
- D) 🧪 Run parallel tests → Data-driven decision

**Next Action**: Test FLUX.2 with multiple reference photos of same character
